# Yshkyn PMS 🏡⚡

> Autonomous smart hub and management system + booking billing for remote guest accommodation facilities.

## 📌 О проекте
**Yshkyn PMS** — это полноценная бэкенд-система и автономный хаб для управления объектами удаленного гостевого размещения (эко-отели, модульные домики, юрты). Система автоматизирует процессы бронирования, биллинга, управления номерным фондом и мониторинга автономных инженерных систем.

## 🛠 Технологический стек
* **Язык и фреймворк:** C#, .NET Core (ASP.NET Core)
* **База данных:** SQLite, Entity Framework Core (EF Core)
* **Инфраструктура и деплой:** Docker, Linux (Ubuntu VDS), Nginx
* **Архитектура:** RESTful API, модульная структура бэкенда

## 🚀 Основной функционал
* **Модуль бронирования и биллинга:** Учет гостей, контроль заезда/выезда, расчет стоимости проживания.
* **Управление номерным фондом:** Администрирование статусов домиков и студий.
* **Автономный хаб:** Подготовка к интеграции с IoT-устройствами и системами контроля энергоснабжения.
* **API и документация:** Наличие эндпоинтов для интеграции с внешними фронтенд-интерфейсами и клиентскими приложениями.
