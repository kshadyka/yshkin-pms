4. Как подключить (чеклист)

  1. dotnet run --urls "http://localhost:5155" или Docker
  2. Открыть /admin → войти (seed: admin / из appsettings)
  3. Проверить /api/version, /api/rooms, /privacy
  4. Telegram: Настройки → integrations bot token + chat id
  5. Карта: Настройки → lat/lng → сайт «На карте»
  6. Платежи: статус вручную + POST /api/billing/test-payment
  7. Прод: reverse proxy на 8080, volume data/ и wwwroot/uploads
